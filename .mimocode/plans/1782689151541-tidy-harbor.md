# Hackathon Mockup Plan: haCARton Satellite Review

## Overview
Replace the existing `app.py` with a streamlined hackathon demo that shows 5 mock work units (65,000 hectare blocks) with synthetic satellite images, mocked classifications, and Portuguese UI buttons.

## Goal
A self-contained Streamlit app that demonstrates the workflow from the novofluxocar diagram:
- Work units sorted by confidence (highest → lowest)
- Each unit shows: raw image, classification, confidence, and 3 action buttons
- No real models or Earth Engine required

---

## Step 1: Rewrite `app.py`

### File: `app.py` (complete rewrite)

**Structure:**
```
1. Imports (streamlit, numpy, cv2, random)
2. CSS styling for buttons (aceito/rejeitado/requer edição)
3. Session state initialization
4. Mock data generation functions
5. Main UI: sidebar + work unit cards
6. Summary metrics at bottom
```

### Mock Image Generation
Create `generate_mock_image()` that produces synthetic satellite-like images:
- Base layer: random gradient of greens/browns (vegetation/soil)
- Patches: rectangles with varying colors (forest green, agriculture brown, water blue)
- Noise: add gaussian noise for realism
- Size: 512x512 pixels

### Work Unit Data Structure
```python
work_units = [
    {
        "id": 1,
        "area_ha": 65000,
        "image": np.ndarray,           # generated mock image
        "classification": "forest",    # from CLASS_NAMES
        "confidence": 0.94,            # sorted desc
        "status": "pending"            # pending | aceito | rejeitado | requer_edicao
    },
    # ... 5 units total
]
```

### Classification Mocking
- Use existing `CLASS_NAMES` from `dw_processor.py`: ["Water", "Trees", "Grass", "Flooded Vegetation", "Crops", "Scrub/Shrub", "Built Area", "Bare Ground", "Snow/Ice"]
- Pre-assign with deliberate confidence gradient: 94%, 87%, 72%, 58%, 45%
- This ensures sorting always works and demo looks compelling

### UI Layout (per work unit)
```
┌─────────────────────────────────────────────────────────┐
│ Work Unit #1 — 65,000 ha                    Confidence: 94% │
├──────────────────────┬──────────────────────────────────┤
│                      │ Classification: Trees            │
│   [Raw Image]        │ Status: ⏳ Pendente              │
│                      │                                  │
│                      │ [✓ Aceito] [✗ Rejeitado] [✎ Requer Edição] │
└──────────────────────┴──────────────────────────────────┘
```

### Button Actions
- **aceito** (green): sets status to "aceito", auto-advances to next
- **rejeitado** (red): sets status to "rejeitado", auto-advances
- **requer edição** (yellow): sets status to "requer_edicao", auto-advances

### Progress & Summary
- Progress bar showing completed units
- Summary section: counts of aceito/rejeitado/requer edição/pending
- "Reiniciar" button to reset all statuses
